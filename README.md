# VSA-SourceGenerators

This repository includes a .NET 10 solution scaffold for Visual Studio and the .NET SDK.

- Solution: `VSA-SourceGenerators.slnx`
- Project: `src/VSA.SourceGenerators/VSA.SourceGenerators.csproj`

To build the solution locally:

```bash
dotnet build VSA-SourceGenerators.slnx
```
